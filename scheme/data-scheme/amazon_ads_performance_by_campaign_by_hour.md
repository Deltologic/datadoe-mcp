# Ads performance by campaign by hour

- BigQuery table name: `amazon_ads_performance_by_campaign_by_hour`
- Available in: Amazon Ads
- Data scheme index: ../data-scheme.md

Advertising performance for each campaign and each Amazon activity hour. Filter on the local date, then group by weekday and local hour and recompute ratios from the summed measures. Hours use the advertiser's Amazon Ads profile timezone, including daylight saving. If that timezone is unknown, the local date, hour, and weekday are null. A null measure is unavailable, not zero. A missing traffic or conversion side stays null. Turning this table on does not mean the stream is subscribed, receiving, or complete for every past hour. This is not the shopper's purchase hour, and it is not hourly profit, fees, or total advertising cost of sales.

## Prerequisites

Requires AMS Traffic and AMS Conversion. Turning this table on can turn those tables on and starts collection for every Sponsored Products, Sponsored Brands, and Sponsored Display dataset they use. This view does not store a second billed copy of those rows. Rows with row billing on a required table still count toward usage.

- `traffic_last_received_at` (`DATE`, nullable) — Latest received time among the traffic events in this row. Null when traffic is absent.
- `conversion_first_received_at` (`DATE`, nullable) — Earliest received time among the conversion events in this row. Null when conversion is absent.
- `conversion_last_received_at` (`DATE`, nullable) — Latest received time among the conversion events in this row. Null when conversion is absent.
- `source_last_updated_at` (`DATE`, nullable) — Latest source dt_updated across the traffic and conversion events in this row.
- `source_presence` (`TEXT`, required) — BOTH, TRAFFIC_ONLY, or CONVERSION_ONLY. This shows which side contributed. It does not mean collection is complete.
- `has_negative_aggregates` (`LOGIC`, required) — True when any summed traffic or conversion measure is below zero. Negative corrections stay in the measure.
- `dt_created` (`DATE`, nullable) — Earliest source dt_created among the events in this row. Not the time this view was built.
- `dt_updated` (`DATE`, nullable) — Same timestamp as source_last_updated_at. Not the current time.
